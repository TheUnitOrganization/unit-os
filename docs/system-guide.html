Unit Linux

Arch + Hyprland on a Ryzen 7 7730U. Built 9–10 September 2026. What it does, how to change it, how to build it again.

Start here

Three ideas and the whole system makes sense.

SUPER is the key. Plus a letter opens an app, plus a number moves you to a workspace, plus SHIFT takes the window with you.

Everything is a text file. No settings app — the window manager, bar, terminal and editor are each a file in ~/.config.

The backup is a git repo. ~/.dotfiles holds every one of those files.

Lost?

SUPER + / — every keybinding, filterable, generated from the config itself, so never stale.

Saving

The one habit that matters.

dots status                # what changed
dots-save                  # commit it all
dots add ~/.config/x.conf  # track a NEW file

Saving only picks up files git already knows. A new config file stays invisible until you dots add it once — so nothing lands in the repo by accident.

Not true yet
  • Autosave is off — the timer is disabled and there's no Claude hook. Saving happens only when you ask.
  • The repo has no remote. The backup is on this disk only.

Turn the hourly save on: systemctl --user enable --now dots-autosave.timer

The look

One command re-skins everything.

theme mecha warm dark · theme mono neutral dark · theme bun ink on cream. Each rewrites Hyprland, waybar, rofi, kitty, dunst, GTK, folder icons and Neovim in one pass. A new palette is one entry in PALETTES at the top of ~/.local/bin/theme.

Wallpapers rotate every 5 minutes from ~/Pictures/wallpapers/favorites; SUPER+SHIFT+B skips ahead. Other sets sit beside it — copy what you like into favorites.

Careful

Files that say generated by theme in line one — hyprpaper.conf, dunstrc, GTK settings.ini — get overwritten on every switch. Edit the render_* function in theme instead.

Rebuild

Empty disk to this desktop.

  1. Install Arch, log in, connect wifi.
  2. sudo pacman -S git base-devel
  3. git clone --bare git@github.com:januarionclx/unit-linux.git ~/.dotfiles
  4. git --git-dir=$HOME/.dotfiles --work-tree=$HOME checkout
  5. bash ~/.local/bin/bootstrap-desktop — packages, services, wallpapers, themes.
  6. Log out and in. gh auth login, opencode auth login.

Step 3 needs that repo to exist. Until then, copy ~/.dotfiles to a USB stick.

Gotchas

Each cost an hour to learn once.

  • Hyprland ≥ 0.55 is Lua. Ricing videos ship the old format — their waybar and kitty parts copy over, the WM config doesn't. hyprctl configerrors after every edit.
  • Test a binding live: hyprctl dispatch '<lua>'.
  • hyprpaper 0.8 wants a wallpaper { } block. Old preload lines fail silently.
  • New keybind not working? The terminal was already open. Programs read config at launch.
  • Claude's ! can't sudo — no TTY. Install in a real terminal.
  • paru is broken here. Use yay.
  • No display manager. ~/.bash_profile starts the session with uwsm start hyprland.desktop after you log in on tty1 — so Hyprland runs as a systemd user session and systemctl --user behaves. A change there is only tested by a reboot, and a bad one makes tty1 a login loop: Ctrl+Alt+F2 is the way out, every time.
  • Only PRINT leaves a file. Region snips are clipboard-only by design, so they die on your next copy — to keep one, use SHIFT+PRINT and press Ctrl+S in swappy. If a shot seems to do nothing, you tapped Print without dragging: that cancels the region select, and shot says so with a notification.
  • Light GTK needs gtk-theme-name=Adwaita, or Thunar keeps black holes.
  • Lost a window? It's on the scratchpad — SUPER+S.
