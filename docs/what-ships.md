# What unit-os ships

The manifest. `unit-doctor` checks the machine against this file, so if you
change what the system is, change it here too.

Read this first when you come back and don't remember what you built.

---

## The one-paragraph version

unit-os is an Arch Linux desktop: **Hyprland** as the compositor, **waybar**
as the bar, **kitty** as the terminal, **Neovim** as the editor, and a single
`theme` command that re-skins all of them from one palette. It is installed by
cloning this repo and running `./install.sh`. Nothing else is required.

---

## The four layers

Everything in this repo is one of four things. If you are lost, find the layer
first, then the file.

| Layer | What it is | Where | Changed by |
|---|---|---|---|
| **1. Packages** | ~83 native + 7 AUR packages | `config/unit/pkglist-*.txt` | `pacman -S`, then refresh the lists |
| **2. Config** | the dotfiles themselves | `config/` | you, in `~/.config/…` |
| **3. Commands** | the scripts on your PATH | `bin/` | you, in `~/.local/bin/…` |
| **4. Themes** | palettes that generate config | `themes/` | adding a theme folder |

Layers 2 and 3 are symlinked back to this repo on this machine, so editing
`~/.config/hypr/binds.lua` *is* editing `config/hypr/binds.lua`. There is no
sync step and nothing to remember.

## Layer 1 — packages

The desktop is these programs. Grouped by what they do, not alphabetically:

| Role | Package | Notes |
|---|---|---|
| Compositor | `hyprland` | 0.56, **Lua** config — online hyprlang snippets will not paste |
| Bar | `waybar` | floating glass pills |
| Terminal | `kitty` | `ghostty` and `alacritty` also installed, for comparison |
| Launcher | `rofi` | `hyprlauncher` also installed, unused |
| Notifications | `dunst` | fully generated by `theme` |
| Lock / idle | `hyprlock`, `hypridle` | dim 5m · lock 10m · screen off 15m |
| Wallpaper | `hyprpaper` | 0.8 `wallpaper { }` syntax; old syntax fails **silently** |
| Editor | `neovim` | 0.12, `vim.pack`, no distro framework |
| Shell | `bash` + `starship` + `fzf` + `zoxide` | every tool guarded — a missing one never breaks the shell |
| Files | `thunar`, `gvfs` | |
| Browser | `brave-bin` (AUR) | needs `ELECTRON_OZONE_PLATFORM_HINT=wayland` |
| Monitor | `btop` | nice -10, CTRL+SHIFT+ESC |
| Screenshots | `grim`, `slurp`, `swappy` | driven by `bin/shot` |
| Clipboard | `cliphist`, `wl-clipboard` | two watchers started in `autostart.lua` |
| Paint | `drawing` | GTK3, so it adds no KF6 dependencies |
| Audio | `pipewire`, `wireplumber` | user units |
| Bluetooth | `bluez`, `blueman` | |
| Power | `power-profiles-daemon`, `brightnessctl` | |
| VPN | `nordvpn-bin` (AUR) | waybar pill in `scripts/nordvpn.sh` |
| Logout menu | `wlogout` (AUR) | |
| AUR helper | `yay-bin` | **use yay, not paru** — paru-bin is built against an older libalpm than pacman 7.1 and dies on start |

Full lists: `config/unit/pkglist-native.txt`, `config/unit/pkglist-aur.txt`.

Refresh them after installing anything you want to keep:

```bash
pacman -Qqen > config/unit/pkglist-native.txt
pacman -Qqem > config/unit/pkglist-aur.txt
```

### Not from a package

Two things on the machine are **not** installed by unit-os and are not in this
repo. `unit-doctor` reports them as informational, never as failures:

| Thing | What | Where it comes from |
|---|---|---|
| `herdr` | persistent agent-session runtime | herdr.dev — a downloaded binary, not Laravel Herd |
| `claude` | Claude Code | its own installer, versioned under `~/.local/share/claude/` |

They are deliberately excluded: both self-update, and a 24 MB binary does not
belong in a config repo.

## Layer 2 — config

One directory per app, mirroring `~/.config/`:

| Path | What it holds |
|---|---|
| `config/hypr/` | 11 Lua/conf files — see `docs/anatomy.md` for the per-file table |
| `config/waybar/` | `config.jsonc`, `style.css`, and 7 pill scripts |
| `config/kitty/` | font, padding, `smart_paste.py` (Ctrl+V that yields to image clipboards) |
| `config/nvim/` | ~150-line `init.lua`, 5 plugins |
| `config/rofi/` | modes and font |
| `config/dunst/` | **generated** by `theme` |
| `config/btop/`, `bat/`, `tmux/`, `swappy/`, `alacritty/` | small, self-explanatory |
| `config/gtk-3.0/`, `gtk-4.0/` | Thunar and every GTK app |
| `config/Thunar/` | custom actions, keyboard accels |
| `config/starship.toml` | **generated** by `theme` |
| `config/mimeapps.list` | default app per filetype |
| `config/unit/` | the package lists |

### Generated files — do not edit these

Nine files are written by `bin/theme` from the active palette. Editing them
works until the next `theme` run eats your change. Edit the matching
`render_*` function in `bin/theme` instead:

```
waybar/colors.css      waybar/shape.css     kitty/colors.conf
alacritty/colors.toml  rofi/theme.rasi      dunst/dunstrc
hypr/colors.lua        starship.toml        nvim/lua/theme.lua
gtk-3.0/gtk.css        gtk-4.0/gtk.css      hypr/hyprlock.conf
```

## Layer 3 — commands

Everything in `bin/` lands on your PATH at `~/.local/bin/`:

| Command | Does |
|---|---|
| `theme` | re-skin everything: `theme terminal` / `theme studio`. The big one — 958 lines. |
| `shot` | every screenshot key routes here — `full`, `region`, `edit` |
| `gen-wallpaper` | draw a wallpaper from the active palette |
| `papirus-variant` | build a recoloured folder-icon theme in `$HOME` (no root, survives updates) |
| `bootstrap-desktop` | packages + services + dirs, for a fresh machine |
| `unit-doctor` | check this machine against the manifest |
| `agent` | spawn a Claude Code session in a new kitty tab |
| `boot-menu`, `setup-boot`, `setup-grub`, `setup-autologin`, `lock-boot` | boot and login chain |
| `dots-autosave` | the old bare-repo saver — **kept, deliberately not enabled** |
| `wall-next`, `mono-folders`, `whatsapp` | small wrappers |

## Layer 4 — themes

Two, both dark, no light side:

| Theme | Look | Neovim |
|---|---|---|
| `terminal` | true black under off-white, **square** corners | `quiet` |
| `studio` | warm greys under parchment, **soft** corners (radius 12) | `gruvbox-material` |

`studio` sits several steps up from `terminal` and covers what a light theme
would give you — which is why neither has a light side. Old names `mono`,
`mecha` and `brown` still resolve.

Shape is per-theme, not a separate setting: `radius` drives Hyprland rounding,
waybar pills, rofi, dunst, GTK menus and kitty tabs together.

## What is deliberately NOT here

| Not shipped | Why |
|---|---|
| `~/Pictures/` — wallpapers, the ANIMA renders | binary, large, and yours |
| `~/Documents/TODO.md`, `sessions/` | your working notes, not the system |
| `~/.config/ai-usage/env` | **live API keys.** gitignored; `install.sh` writes a commented template |
| `~/.ssh/`, `~/.npmrc`, `~/.claude.json` | credentials |
| `~/.config/themes/current`, `wallpaper` | runtime state — which theme is on right now |
| `herdr`, `claude` binaries | self-updating, and 24 MB |
| Brave/dconf/pulse profiles | generated user state, not config |

---

## The clean base

`./install.sh --link` on this machine, `./install.sh` on a fresh one, gets you
back to exactly what this manifest describes. `unit-doctor` tells you how far
the current machine has drifted from it.

That is the whole point of the repo: **a known-good state you can always
return to.**
