Neovim

A hand-written config, about 150 lines, on Neovim 0.12's built-in vim.pack. Five plugins, no distribution. Leader is SPACE.

The ten that matter

I … ESCThe whole trick. I starts typing, ESC stops. In normal mode the letters are commands, not text.
:w :q :q!Write · quit · quit throwing changes away
HJKLLeft, down, up, right — the same keys as Hyprland and tmux
DDDelete the line. 3dd deletes three.
YY / PCopy a line / paste it after the cursor
U / CTRL+RUndo / redo — undo survives quitting
/word then NSearch, then next hit
GG / GTop / bottom of file. :42 jumps to line 42.
W B 0 $Word forward, word back, start of line, end of line
ciwChange inner word — deletes the word under the cursor and starts typing
Why the last one matters. Vim is a grammar: verb + noun. Verbs are d delete, c change, y yank. Nouns are w word, iw inner word, i" inside quotes, ip paragraph. They multiply — d2w, ci", yap, di( all fall out of the ten above without being memorised separately.

This config's keys

SPACE+W / QSave / quit
-File browser (oil) — it's a normal buffer. Rename by editing the line, dd to delete, :w to apply.
SPACE+FFind files
SPACE+GGrep the whole project — ripgrep
SPACE+B / ROpen buffers / recent files
SPACE+GGGit — status, diff, stage, commit (neogit)
CTRL+HJKLMove between splits
GD / KGo to definition / hover docs (needs an LSP attached)
Stuck? Press ESC twice. If that fails, :q! then Enter quits without saving.
